# the truth factory — app

This folder is a Capacitor project that wraps a small swipeable-card web app
(`app/www/`) built from the exact same cards as the website
(`src/cards/*.md`). It does not touch anything in the existing 11ty site.

## What's here

```
app/
  www/                  the app's UI: index.html, styles.css, app.js, cards.json (generated)
  capacitor.config.json
  package.json
  android/               native Android project (generated by `npx cap add android`)
  ios/                   native iOS project (generated by `npx cap add ios`)
scripts/
  build-cards-json.mjs   reads src/cards/*.md -> writes app/www/cards.json
.github/workflows/
  build-android.yml      CI: builds a debug .apk on every push, no account needed
  build-ios.yml           CI: builds for the iOS Simulator only (no Apple account yet)
```

## How to add this to your repo

1. Copy the `app/` folder, `scripts/` folder, and the two new files under
   `.github/workflows/` into the root of `sj-on.github.io`, alongside the
   existing `src/`, `.eleventy.js`, etc.
2. Add this line to the repo's root `.gitignore` (already done here — copy
   the relevant block over if you're merging by hand):
   ```
   app/android/app/build/
   app/android/.gradle/
   app/android/local.properties
   app/ios/App/Pods/
   app/ios/App/build/
   app/ios/App/DerivedData/
   app/www/cards.json
   ```
3. Commit and push. That's it for CI — the two new workflows only run when
   you touch `src/cards/**` or `app/**`, so they won't interfere with your
   existing `deploy-pages.yml`.

## Running it locally

You'll need Node installed (you already have this for the 11ty site).

```bash
# from the repo root
node scripts/build-cards-json.mjs   # generates app/www/cards.json
cd app
npm install
npx cap sync                        # copies www/ into android/ and ios/
```

**To try the UI in a normal browser** (fastest way to see it, no phone/emulator needed):
```bash
cd app/www
python3 -m http.server 8000
# open http://localhost:8000 — swipe with the mouse, or use arrow keys
```

**To run it on an Android emulator or device:** install Android Studio, then
```bash
npx cap open android
```
and hit Run in Android Studio. First time only — this is the "hello world"
step that didn't click years ago; happy to walk through it live if it snags.

**To run it on iOS:** you'll need a Mac with Xcode installed.
```bash
npx cap open ios
```
Since there's no Apple Developer account yet, you can still run it on the
iOS **Simulator** for free — you just can't install it on a real iPhone or
submit it anywhere until you enroll.

## Every time you add or edit a card

Nothing extra to do. Add/edit the `.md` file in `src/cards/` like you
already do, push to `main`, and:
- the website rebuilds via the existing `deploy-pages.yml`
- the Android debug APK rebuilds via `build-android.yml` (download it from
  the Actions run's "Artifacts" section)
- the iOS simulator build rebuilds via `build-ios.yml`

Both the site and the app read the same source files, so they can't drift
out of sync.

## What's deliberately not done yet

- **App icon / native splash image** — currently using Capacitor's default
  icon. Easy to swap in later (a real "tf" mark asset would help here).
- **Signed release builds** — both workflows produce unsigned/debug builds
  for testing. Signing for the Play Store or App Store is a deliberate
  later step once you're ready to publish, since it involves accounts and
  secrets you'll want to set up yourself.
- **iOS on a real device** — blocked on the Apple Developer account.
